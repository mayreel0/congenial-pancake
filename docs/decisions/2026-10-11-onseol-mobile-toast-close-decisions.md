# 모바일 토스트 닫기 표시 크기와 정렬 (DEV-97)

## 배경

사용자는 2026-10-10T16:04:01Z 댓글에서 모바일 기기로 확인했으며 드래그 동작과 색상에 만족한다고 밝혔다. 남은 요청은 작은 닫기 표시를 키우고, 두 줄 메시지에서도 첫 줄 대신 토스트 중앙에 배치하는 것이다.

## 결정과 근거

닫기 문자 크기를 모바일에서 18px에서 24px로 키우고 버튼에 `self-center`를 적용한다. 메시지 줄 수에 따라 높이가 늘어도 닫기 버튼은 세로 중앙에 위치한다. 기존 44px 최소 터치 영역과 접근 가능한 이름, 키보드 조작을 유지한다. 데스크톱 문자 크기는 18px를 유지한다.

## 산출물

`packages/ui/src/components/Toast.tsx`의 닫기 버튼 클래스만 수정했다. 드래그와 색상, 토스트 패딩은 그대로 유지했다.

## 검증

사용자의 2026-10-10T16:04:01Z 실기기 확인은 수정 전 드래그와 색상에 대한 것이다. 닫기 버튼 수정 이후인 2026-10-10T16:19:17Z 댓글에서 사용자는 “실제 모바일 기기와 스토리북에서 동작을 다 확인했고 UI 도 만족스럽습니다”라고 확인했다. 이 후속 확인으로 닫기 표시 크기와 중앙 정렬의 시각 확인 대기를 해소한다.

제공된 2026-10-10T16:09:17Z Orchestrator 보고는 닫기 버튼 수정 이후 Gate 1 필수 검증 23개 통과를 기록한다. 이는 전달받은 결과이며, 이 세션에서 검증 게이트나 브라우저를 실행한 결과는 아니다. 기기·브라우저 종류 및 스크린리더 등 개별 점검 항목의 상세 결과는 제공되지 않았으므로 별도로 통과했다고 단정하지 않는다.
