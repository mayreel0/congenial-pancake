# 네이버 로그인 재노출 (DEV-46)

## 배경

2026-10-12 사용자 댓글에서 네이버 검수 완료 및 서비스 적용을 확인하고, 네이버 로그인은 다시 노출하되 카카오는 계속 숨기도록 확정했다. 이 결정은 2026-10-03 임시 노출 제한 기록의 네이버 숨김 결정을 대체한다.

## 결정

- `/login`과 `/me`의 공개 제공자는 Google과 네이버로 통일한다.
- 카카오 로그인·신규 연동 진입점은 숨기고, `/me`의 기존 카카오 연동 상태는 계속 표시한다.
- 백엔드 OAuth 구현은 유지한다.

근거: 네이버의 공개 전환이 확인되었으므로 진입점을 복구한다. 카카오에는 기존 제한과 연동 상태 보존 규칙을 적용한다.

## 산출물

- `PUBLIC_OAUTH_PROVIDERS`에 `naver`를 추가했다. 기존 `/me` 필터가 이를 사용하여 네이버 연동 타일을 표시한다.
- 충돌 해결 중 `/login`에 생긴 별도 목록을 제거하고 공유 목록을 다시 사용한다.
- 최신 base의 가입 동의 확인, 처리 중 버튼 비활성화, 소셜 회원가입 구분 및 최근 로그인 배지는 유지한다.

## 검증

관련 소스와 변경 내용을 읽어 확인했다. 이번 실행에서는 사용자 제한에 따라 테스트·빌드·브라우저 검증·외부 검증 게이트를 실행하지 않았다. 이전 실행의 검증 결과를 이번 변경의 통과 근거로 사용하지 않는다.

## 남은 일

### 전달된 Gate 1 실패에 대한 수정

- 가입 동의 테스트가 카카오 링크를 계속 기대하여 실패했다. 기대 제공자를 Google·네이버로 갱신하고, 로그인 및 가입 동의 전후에 카카오 버튼이 없다는 단언을 추가했다. 공개 제공자의 동의 전 비활성화·동의 후 가입 URL·동의 취소 검사는 유지했다.
- 알림 테스트에서 `window.matchMedia is not a function`이 발생했다. 해당 파일의 `afterEach`가 공통 정리 전에 `vi.unstubAllGlobals()`를 호출할 수 있어, 중복 훅을 제거하고 `vitest.setup.ts`의 `cleanup()` → `vi.unstubAllGlobals()` 순서를 사용하도록 했다.
- 실패 로그와 소스를 근거로 수정했으며 테스트 재실행은 하지 않았다. 통과 여부는 Orchestrator의 후속 검증에서 확인해야 한다.

### 후속 확인

- 별도 검증 단계에서 Google·네이버 로그인/연동 진입점, 카카오 신규 진입점 숨김 및 기존 연동 상태 표시를 확인한다.
- 카카오 공개 전환은 이번 범위 밖이며 별도 결정 전까지 숨김을 유지한다.
