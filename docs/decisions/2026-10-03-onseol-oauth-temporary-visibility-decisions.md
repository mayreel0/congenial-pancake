# 소셜 로그인 임시 노출 제한 (DEV-46)

## 배경

카카오·네이버 로그인이 테스트 계정에서만 동작하므로 일반 사용자에게 실패하는 진입점이 노출된다. DEV-46에서 공개 전환 전까지 버튼을 숨기되 기존 연동 상태는 표시하도록 범위를 확정했다.

## 결정

- `/login`에는 공개 제공자인 Google만 표시한다.
- `/me`에는 공개 제공자와 이미 연동된 제공자만 표시한다. 카카오·네이버는 연동된 경우 기존 체크 배지를 유지하고 신규 연동 링크는 숨긴다.
- 백엔드 OAuth 구현과 제공자별 아이콘은 유지한다.

근거: 일반 사용자의 실패를 방지하면서 기존 테스트 계정의 연동 정보는 보존하고, 공개 전환 시 제공자별로 노출을 복구할 수 있다.

## 산출물

`oauthProviders.tsx`의 `PUBLIC_OAUTH_PROVIDERS`를 두 화면에서 공유한다. 현재 값은 `google`뿐이다. 계정 정보 로딩 중에도 공개 제공자에 대해서만 스켈레톤을 표시한다.

## 검증

사용자 지시에 따라 테스트, 빌드, 브라우저 검증 및 외부 검증 절차는 실행하지 않았다. 런타임 검증 완료를 의미하지 않는다.

## 남은 일

- 후속 검증에서 `/login`의 Google 단독 노출, `/me`의 미연동 카카오·네이버 숨김 및 기존 연동 상태 표시를 확인한다.
- 각 제공자의 공개 전환이 확정되면 `PUBLIC_OAUTH_PROVIDERS`에 해당 제공자를 추가한다. 공개 전환 자체는 이번 범위 밖이다.
