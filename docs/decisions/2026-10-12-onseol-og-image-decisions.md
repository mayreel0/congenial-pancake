# 온설 OG 이미지 — DEV-44

## 배경

기존 텍스트 중심 OG 시안은 디자인 문제로 보류되었다. 기존 말풍선 아이콘과 서비스 소개를 조합한 로컬 미리보기를 제공했고, 사용자는 2026-10-11 댓글에서 시안을 확인한 뒤 아이콘에 border radius를 주어 모바일 앱 아이콘처럼 보이도록 요청했다. 이 댓글을 기존 시안에 대한 수정 방향으로 적용했다.

## 결정과 근거

- 기존 `icon-512.png`를 그대로 원본으로 사용하고, OG 이미지 안에서만 440px 정사각형에 96px 모서리 반경을 적용한다. **근거:** 사용자가 요청한 앱 아이콘 형태를 반영하며 원본 앱 아이콘은 보존한다.
- 기존 서비스명과 소개 문구, 어두운 배경의 시안 구성을 유지한다. **근거:** 사용자 피드백의 변경 대상은 아이콘 모서리다.
- 완성된 1200×630 PNG를 OG와 Twitter에서 공유한다. **근거:** 공유 요청 시 별도의 이미지 생성이나 폰트 다운로드가 필요 없고, 로컬 미리보기와 실제 배포 이미지가 동일하다.

## 산출물

- `apps/web/public/og-image.png`: 둥근 앱 아이콘과 한글 문구를 포함하는 공유 이미지.
- `apps/web/app/layout.tsx`: OG 이미지 URL·크기·MIME 타입·대체 텍스트 및 Twitter 이미지 연결.
- `docs/previews/dev-44-og.html`: 완성된 PNG의 전체 크기와 360px 축소 미리보기. 브라우저에서 파일을 직접 열 수 있다.
- `docs/previews/generate-dev-44-og.js`: macOS AppKit으로 PNG를 재생성하는 소스. 저장소 루트에서 `osascript -l JavaScript docs/previews/generate-dev-44-og.js` 실행. Apple SD Gothic Neo를 사용하며 앱 실행·배포에는 macOS 의존성이 없다.

## 검증

- PNG를 생성하고 이미지 뷰어로 둥근 모서리, 아이콘 방향, 한글 문구 표시를 확인했다.
- Swift 기반 생성은 도구가 워크트리 밖 임시 파일을 요구해 차단되었다. 최종 생성 소스는 컴파일이 필요 없는 AppKit JavaScript 방식이다.
- AppKit 브리지의 빈 사전 전달과 그래픽 컨텍스트 설정 문제를 수정한 뒤 최종 PNG를 생성했다.
- 사용자 제한에 따라 테스트·빌드·브라우저 검증 게이트, 외부 연동, 리뷰, 커밋·푸시·PR 작업은 수행하지 않았다. 실제 공유 서비스에서의 표시와 캐시 갱신은 확인하지 않았다.

## 남은 일

구현 차단 사항 없음. 배포 후 공유 서비스에서 이미지를 가져오는 동작은 이 작업에서 검증하지 않았다.

## 리뷰 피드백 반영

수정: Codex. 전달된 독립 리뷰에 대한 로컬 수정이며, 재검토는 수행하지 않았다. 사용자 제한에 따라 커밋 SHA와 PR 응답은 생성하지 않았다.

- **반영 — 생성 스크립트의 knip 미사용 파일 가능성:** 루트 워크스페이스의 `ignore`에 `docs/previews/generate-dev-44-og.js` 한 파일만 추가했다. 이 파일은 `osascript` 인자로 직접 실행되므로 import 그래프에 나타나지 않는다. 기존 k6 시나리오 제외 방식과 맞췄으며 `docs/previews/**` 전체를 제외하지 않았다. knip 실패가 실제 재현된 것은 아니며, 사용자 제한에 따라 수정 후 knip도 실행하지 않았다.
- **반영 — 이미지 메타데이터 중복:** `OG_IMAGE`에 URL과 대체 텍스트를 모으고 기존 `TITLE`·`DESCRIPTION`으로 대체 텍스트를 구성했다. OG와 Twitter가 이를 함께 사용한다.
- **반박 — 이번 실행에서 브라우저 검증 요구:** 현재 사용자 지시가 검증 게이트와 외부 연동을 명시적으로 금지하므로 실행하지 않는다. 앞선 미검증 기록을 그대로 유지하며 통과를 주장하지 않는다.
- **반박 — 글꼴 변경 제안:** 시안 확인 후 사용자가 요청한 변경은 아이콘 모서리다. 이 수정에서 새 글꼴로 디자인을 바꾸지 않는다. 기존 PNG와 macOS 전용 생성 방식은 유지하며, 이 의존성은 이미지 재생성에만 적용된다.
