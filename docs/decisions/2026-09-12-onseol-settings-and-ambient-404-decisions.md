# 온설 /settings 신설 + 404 앰비언트 배경 + 기록탭 동기화 버그 결정 기록

> 메모리 요약([[settings_page_backlog]], [[ambient_mood_404_page]], [[records_tab_sync_bug]])과 PR 기록을 대조해 재구성.

## 결정 1: /settings 페이지 신설 (PR #200)

테마·앰비언트 무드·모션(애니메이션 줄이기)·404 배경 켜짐 여부를 한 곳에 모은 설정 페이지. 전부 **로컬스토리지 전용, 즉시 적용**(서버 저장 없음, 계정 간 동기화 없음) — 로그인 여부와 무관하게 기기별 취향으로 취급. 이후 웹 푸시 토글도 이 페이지로 옮겨짐([[Onseol Roadmap]]류 후속 작업, 별도 문서 `2026-09-19-onseol-pwa-web-push-decisions.md` 참고).

## 결정 2: 404 페이지에 계절×시간대 캔버스 배경 (PR #199)

`AmbientScene` — 현재 계절과 하루 중 시간대를 조합해 캔버스로 그리는 배경을 404 페이지에 적용. 픽셀아트 스타일은 검토했으나 이번 라운드에서는 채택하지 않음(보류, 재검토 없음).

## 결정 3: /records 탭 상태가 이미 열린 페이지에서 URL과 안 맞는 버그 (PR #226)

`?tab=` 쿼리로 탭을 바꾸는데, 이미 마운트된 `/records` 페이지에서 쿼리만 바뀌는 내비게이션(예: 알림 클릭으로 다른 탭 딥링크 진입)이 반영 안 되던 버그. `ref`로 가드한 `useEffect`가 `?tab=` 변경을 추적해 이미 마운트된 페이지에서도 탭을 동기화하도록 수정.

## 검증

- 각 PR typecheck/lint/유닛테스트 통과.
- /settings는 각 토글이 새로고침 후에도 유지되는지 로컬스토리지 확인.
- 404 배경은 여러 계절/시간대 값을 강제로 넣어 캔버스 렌더링 확인.
- #226은 알림 딥링크로 실제 탭 전환까지 실서버에서 확인.
