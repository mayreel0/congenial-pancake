# 온설 보안 점검(2026-09) 결정 기록

> 메모리 요약([[security_review_2026_09]])과 PR 기록을 대조해 재구성. PR #228이 중심, 관련해 #220/#241/#242/#244/#246–#248도 같은 시기의 보안 강화 작업.

## 배경

범위를 정해 5개 항목을 점검하는 보안 리뷰를 진행(PR #228): 세션/비밀번호 처리, 인증 관련 rate-limit, IDOR(권한 없는 리소스 접근), admin 인증.

## 결과: 실제로 발견된 것은 pnpm audit 취약점 하나뿐

점검 대상 4개 항목(세션/비밀번호, 인증 rate-limit, IDOR, admin 인증)은 모두 이미 안전하게 처리돼 있는 것으로 확인됨 — 추가 코드 변경 없음. 유일한 실제 발견은 **`pnpm audit`에서 Next.js의 critical RCE 취약점 2건**이었고, 의존성 업데이트로 해결해 취약점 0건 상태로 만듦.

## 참고: 부하 테스트 도구의 ThrottlerGuard 우회 코드는 취약점이 아님

`app.module.ts`에 부하 테스트용으로 `ThrottlerGuard`(rate-limit)를 우회하는 코드가 있는데, 이건 `NODE_ENV` 체크로 이중으로 게이트돼 있어 프로덕션에서는 활성화되지 않음 — 설계상 안전. 향후 리뷰에서 `NODE_ENV` 가드 여부를 확인하지 않고 바로 취약점으로 플래그하지 않도록 남겨둠([[load_test_tooling]] 참고).

## 관련 후속 보안 작업(메모리 근거 없음, PR 번호만)

같은 시기에 보안 관련 개별 PR들이 더 있었음: #220, #241, #242, #244, #246, #247, #248. 이 문서에는 구체적 근거(리뷰 대화, 재현 시나리오)가 남아있지 않아 지어내지 않고, 색인 문서(`2026-09-2x-onseol-misc-backlog-index.md`)에 PR 번호와 병합일만 남김.

- 나머지 4개 항목은 코드 리딩 기반 점검(재현 스크립트 등 별도 증적 없음).
