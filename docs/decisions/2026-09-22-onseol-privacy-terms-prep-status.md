# 온설 이용약관/개인정보처리방침 준비 현황 (진행 중 — 코드 없음)

이 문서는 완결된 결정 기록이 아니라, `/terms`·`/privacy` 페이지를 실제로 만들기 전까지의 **진행 상황과 다음 세션이 이어받아야 할 미결 사항**을 남기기 위한 문서다. 아래 정해진 것들은 모두 사용자와 채팅으로만 확정됐고 아직 코드/문서 어디에도 반영되지 않았다.

## 확인한 공식 출처

- 개인정보 처리방침: [개인정보 처리방침 작성지침(2025.4.)](https://www.privacy.go.kr/front/bbs/bbsView.do?bbsNo=BBSMSTR_000000000049&bbscttNo=20806) — 개인정보 포털이 2025-04-21 공개. 자동 작성 도구는 검색으로 확인 못 함(앞서 있다고 잘못 말한 적 있음, 정정) — 지침 기준으로 직접 작성.
- 이용약관: 공정위 [표준약관 목록](https://www.ftc.go.kr/www/selectBbsNttList.do?bordCd=201&key=202)에 이 서비스(결제 없는 익명 게시 서비스) 성격에 맞는 표준약관 없음 확인. [약관의 규제에 관한 법률](https://law.go.kr/LSW/lsInfoP.do?lsId=000667&ancYnChk=0)의 원칙에 맞춰 직접 작성하기로 함.
- 개인정보 처리방침 필수 기재사항(PIPC 포털 확인): 처리 목적, 처리·보유기간, 개인정보파일 등록현황, 제3자 제공, 처리위탁, 파기절차·방법, 정보주체 권리·행사방법, 안전성 확보조치, 자동수집장치(쿠키), 보호책임자, 열람청구 접수부서.

## 코드에서 확인한 실제 처리 사실(문서 초안의 재료)

- **회원 정보**: 이메일, 비밀번호 해시, 닉네임, 이메일 인증 시각, 소셜 로그인(구글/카카오/네이버) 식별자.
- **작성한 글**: 고민/답장 본문, 익명 여부, 신고·숨김 상태.
- **비회원(게스트)**: `guest_id` 쿠키(24시간, httpOnly) — 작성 횟수 제한용.
- **세션**: 로그인 세션 쿠키 30일(httpOnly), 접속 기기 정보(User-Agent) 저장.
- **푸시 알림**: 기기 구독 정보(endpoint) 저장.
- **삭제/탈퇴**: 탈퇴는 30일 유예 후 이메일을 가짜 주소로 치환하고 닉네임·비밀번호 해시 삭제, 소셜 연동 해제, 푸시 구독·알림 내역 삭제(단 작성한 글/답장 행 자체는 남고 익명으로 렌더링됨 — 2026-09-09 own-content-deletion 결정과 동일 원칙). 삭제한 글/답장 원문은 30일 뒤 자동 파기(2026-09-22 content-retention 문서 참고, 이번에 실제로 구현함).
- **답장 검열**: 등록하려는 답장 텍스트가 **OpenAI로 전송**됨(국외 처리) — 분류/사유/제안이 검토 로그에 저장됨. 처리방침에 반드시 밝혀야 하는 항목으로 판단.
- **외부 서비스(처리위탁/제3자 처리자)**: AWS(서버/DB/메일 발신), Vercel(웹 호스팅), Resend(메일 발송), OpenAI(답장 검열), 구글/카카오/네이버(소셜 로그인).
- **확인 못 한 것**: IP 주소를 앱 코드가 직접 저장하는 곳은 못 찾음. 다만 AWS/Vercel 인프라 자체의 접속 로그에는 남음 — 이 부분을 처리방침에 어떻게 적을지는 아직 결정 안 됨.

## 사용자와 확정한 것(채팅에만 있음, 코드/문서 반영 전)

- 가입 연령: **만 14세 이상만 가입** — 약관에 명시, 가입 화면에 별도 연령 확인 단계는 없음(약관 동의로 갈음).
- 개인정보 보호책임자 표기: **실명 + "운영자"** 형태로 표기하기로 함. **실명 자체를 아직 못 받음 — 다음 세션에서 반드시 물어봐서 채워야 함.**
- 보호책임자 연락처: `admin@onseol.com` (이메일 전달 설정 완료·수신 확인됨, 2026-09-22 admin-email-forwarding 문서 참고).
- 가입 화면 동의 방식: **필수 체크박스** — "만 14세 이상이며 이용약관·개인정보처리방침에 동의합니다" 형태.

## 아직 전혀 시작 안 한 것

- `/terms`, `/privacy` 페이지 자체(초안조차 없음).
- 가입 화면의 동의 체크박스 UI.
- 웹 푸터의 약관/처리방침 링크 연결(페이지가 없어 의도적으로 보류 중 — 2026-09-21 landing-web-only 문서 참고).

## 다음 세션이 할 일

1. 사용자에게 개인정보 보호책임자 실명을 받는다.
2. 위 "코드에서 확인한 사실"을 바탕으로 처리방침/약관 초안을 작성하고, 사용자 검토를 받는다(법률 자문이 아니므로 공개 전 별도 확인 권장이라는 점을 문서에도 명시).
3. `/terms`, `/privacy` 페이지 + 가입 동의 체크박스 + 푸터 링크를 구현한다.
