## 이 문서의 한계

- 위 항목들은 "언제 무엇을 병합했는가"의 사실만 보증한다. "왜 그렇게 결정했는가", "어떤 대안을 검토하고 버렸는가"는 이 문서에 없다.
- 실제 배경이 필요해지면 `gh pr view <번호> --comments`로 원본 리뷰 대화를 확인할 것 — 이 문서를 근거로 추가 추론하지 말 것.
