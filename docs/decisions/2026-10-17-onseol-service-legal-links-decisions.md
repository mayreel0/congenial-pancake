# 서비스 내부 약관·처리방침 접근 경로 (DEV-101)

## 배경

기존 약관·처리방침 링크는 랜딩과 법률 문서의 푸터에만 있었다. 설치형 앱은 랜딩을 건너뛰므로 로그인 이후 서비스 내부에서도 문서에 접근할 경로가 필요했다.

## 결정 및 근거

2026-10-17 사용자 댓글(13:26:29 UTC)에서 `/me`(내 정보)의 공개 설정 아래·회원탈퇴 위에 ‘약관 및 정책’ 영역을 배치하는 안을 확정했다.

- ‘이용약관’은 `/terms`, ‘개인정보처리방침’은 `/privacy`로 연결한다.
- 근거: 기존 내 정보 진입 경로를 이용해 로그인한 사용자가 정책 문서를 찾을 수 있고, 공개 설정과 회원탈퇴 사이에 독립된 영역으로 구분할 수 있다.

## 산출물

- `apps/web/app/me/components/LegalLinksSection.tsx`: 기존 내 정보 카드 스타일에 맞춘 제목과 두 링크. 모바일 터치 영역과 키보드 포커스 표시를 제공하며 같은 창에서 이동한다.
- `apps/web/app/me/MePageContent.tsx`: 로그인한 사용자 화면에서 공개 설정 폼 다음, 회원탈퇴 이전에 영역을 배치한다.

## 검증

- 소스 확인: 두 목적지 페이지가 존재하며, 링크 영역은 공개 설정 폼 밖의 형제 요소로 배치했다.
- `pnpm --filter web test -- app/me/page.test.tsx` 실행 시 종료 코드 127, `zsh:1: operation not permitted: pnpm`으로 실행 불가.
- `pnpm --filter web typecheck`도 종료 코드 127, `zsh:1: operation not permitted: pnpm`으로 실행 불가.
- 로컬 Next.js 가이드 경로 `apps/web/node_modules/next/dist/docs`는 존재하지 않았다. 기존 저장소의 `next/link` 사용 패턴을 따랐다.
- 테스트·타입 검사 통과나 브라우저·실기기 확인을 주장하지 않는다.

## 남은 일

구현상 미결정 사항은 없다. 실행 가능한 환경에서 테스트·타입 검사와 화면 이동을 확인해야 한다.
